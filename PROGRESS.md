**Источник требований:** [`docs/ТЗ_ERP_WMS_CHAT_TASK_MANAGER.md`](docs/ТЗ_ERP_WMS_CHAT_TASK_MANAGER.md) (разделы 1–36 и приложения A–N).
**Утверждённые решения:** [`docs/decisions.md`](docs/decisions.md).
**Дата инвентаризации:** 14.11.2026, ветка `arena/59d5663c-supply-wasm` (PR #1).

## Как читать этот файл

Файл отвечает на три вопроса по каждой **отдельной** функции ТЗ: сделано ли это, насколько сделано и что осталось. Обобщения («модуль почти готов») здесь не используются — каждый пункт проверяем по коду.

**Статусы**

| Статус | Значение |
| --- | --- |
| `DONE` | Работает в коде, подключено к API и к UI/серверу, есть проверка (тест или подтверждённый ручной прогон) либо это чисто серверная/документная часть без UI |
| `PARTIAL` | Реализована часть сценария: есть API без UI, есть UI без части операций, или не выполнены обязательные проверки |
| `NOT STARTED` | Кода нет |
| `BLOCKED` | Нужно решение пользователя/предприятия, реализация не может начаться |

**Уверенность**

- `высокая` — подтверждено чтением сервиса, маршрута, миграции и теста;
- `средняя` — код есть, но нет подтверждения выполнения теста или браузерной проверки в текущей среде;
- `низкая` — выведено косвенно (например, по наличию таблиц миграции без сервисного слоя).

**Важно про проверки.** При первичной инвентаризации в среде агента не было JDK, Gradle-кэша и PostgreSQL, а таблица подключалась как пустой Git submodule `vendor/ComposeDataGrid` (удалён по D-54); ранние утверждения «тесты проходят» взяты из `docs/features.md`/`TASKS.md` и помечены `средней` уверенностью. Последующие итерации содержат собственные фактические результаты запусков; среда и состав проверок могут отличаться между итерациями.
