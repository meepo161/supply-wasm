# Каталог сценариев по вкладкам — 22.11.2026

Каталог перечисляет ситуации, которые проверяются (или должны проверяться) на каждой вкладке и на стыках вкладок. Он нужен для планирования проверок и **не расширяет объём работ** (по аналогии с `docs/wms-erp-100-scenarios.md`).

Обозначения покрытия:

- **R** — `SmokeApiRobustnessTest`, автоматически для каждого маршрута вкладки: аноним → 401; без прав → не 2xx и не 5xx; битый JSON; пустое тело; несуществующий id; `id=abc`.
- **S** — `SmokeRealScenariosTest` (номер сценария S1–S7).
- **E** — существующие интеграционные тесты `server/src/test` (указан класс).
- **M** — только ручная проверка в браузере (UI-поведение).
- **D** — подтверждённый дефект (ID из `2026-11-22-system-audit.md`).

Матрица R даёт **1401 автоматическую ситуацию** по 332 маршрутам; ниже — смысловые сценарии.

## Как запускать

```powershell
$env:ERP_TEST_DB_PORT = "5434"; ./gradlew.bat --no-daemon :server:test --tests "org.example.project.smoke.*"
```

Без `ERP_TEST_DB_PORT` используется порт 5433 из `docker-compose.yml`. Отчёт по матрице: `server/build/smoke-reports/api-robustness.md`.
