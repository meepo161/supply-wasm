## Как работает классификация известных дефектов

`SmokeApiRobustnessTest.knownDefect` относит расхождение к AUDIT-01, AUDIT-09 или PUSH-503. Набор падает только на **новых** расхождениях, поэтому сразу ловит регрессию или новый эндпоинт без валидации. После исправления дефекта его правило удаляется, и тест начинает охранять корректное поведение. Сквозные сценарии фиксируют дефекты через `report(...)` (строки `SMOKE-FINDING` в выводе); после исправления такую проверку стоит заменить на `assert`.
