# Браузерная QA-проверка: снабжение, склад, справочники (24.11.2026)

Три QA-агента вручную прошли клиент (`http://localhost:8081`, аварийный администратор), каждый — свой участок, ~245 действий. Ключевые находки перепроверены по коду главным агентом. Скриншоты лежали во временной папке сессии и в репозиторий не входят.

Серьёзность: **К** — критично (ломает сценарий или искажает учёт), **В** — важно, **М** — мелочь.
Статус: **Исправлено**, **Решение** — нужно решение пользователя (меняет бизнес-правило или требует новой функции), **Бэклог** — не исправлено в этой итерации.
